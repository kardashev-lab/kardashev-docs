# Roadmap

kardashev is actively maintained by a single developer at Kardashev Labs. There's no fixed timeline, but the known open gaps are:

- **Interconnection queue coverage** — the hosted API currently refreshes queue data daily for NYISO, PJM, and ISO-NE. CAISO, ERCOT, MISO, and SPP queue data is not yet on the same live pipeline.
- **Direct-access parity** — `PJM` currently only exposes LMP directly (requires a free DataMiner2 account); fuel mix, load, and other PJM datasets are only available today through the hosted `Client`.

Track progress in the [Changelog](/changelog), or open an issue on [GitHub](https://github.com/kardashev-lab/kardashev-py/issues).
