# Quickstart

## Python

### Install

```bash
pip install kardashev
```

Requires Python 3.9+.

### Direct ISO access (no API key)

```python
from kardashev import CAISO, ERCOT, MISO, NYISO, ISONE, SPP

caiso = CAISO()
df = caiso.get_fuel_mix()           # live generation by fuel type
df = caiso.get_load()               # actual grid load
df = caiso.get_lmp(market="RT")     # real-time LMP
df = caiso.get_curtailment()        # solar + wind curtailment
```

### Hosted API (all 7 ISOs, normalized)

```python
from kardashev import Client

kl = Client()

fuel = kl.fuel_mix(iso="CAISO")
carbon = kl.carbon(iso="ERCOT")
prices = kl.lmp(iso="MISO", market="RT", limit=50)
queue = kl.queue(iso="PJM")
```

## JavaScript / TypeScript

### Install

```bash
npm install kardashev
```

Requires Node.js 18+ (uses the built-in `fetch`). Also works in browser/edge runtimes.

### Hosted API (all 7 ISOs, normalized)

```ts
import { Client } from "kardashev";

const kl = new Client();

const fuel = await kl.fuelMix("CAISO");
const carbon = await kl.carbon("ERCOT");
const prices = await kl.lmp("MISO", { market: "RT", limit: 50 });
const queue = await kl.queue({ iso: "PJM" });
```

There is no direct no-key ISO scraper in the JavaScript client today - only the hosted API. Python has both. See [Supported ISOs](/supported-isos) for the full breakdown.

See [API Reference](/api-reference) for the full method list in both languages.
